

## Estique — Nail Salon Website

Build a luxurious nail salon website matching the provided design reference.

### Design System
- **Primary**: #A68966 (gold/brown) — buttons, accents
- **Secondary**: #E3D5CA (warm beige) — section backgrounds
- **Neutral**: #FAF9F6 (off-white) — page background
- **Headline font**: Noto Serif (Google Fonts)
- **Body/Label font**: Manrope (Google Fonts)

### Pages & Sections (Single-page landing)

1. **Top Bar** — Phone number (123 456 7890), hours (Mon-Sat: 9am-7pm)
2. **Navigation** — Links: Home, About, Services, Gallery, Pricing, Contact + centered Estique logo with bow icon + "Book Online" CTA button
3. **Hero Section** — "Experience Quiet Luxury" headline, welcome paragraph, "Book an Appointment" button, decorative sparkle icons, background with soft floral/nail imagery using warm gradient overlay
4. **About Section** — "ABOUT ESTIQUE" label, "Refined Beauty & Elegance" heading, description paragraph, "Learn More" button, placeholder image of salon interior
5. **Services Section** — "LUXURIOUS NAIL CARE" label, "Our Signature Services" heading, 4 service cards with placeholder images (manicure, pedicure, nail art, spa treatment), "View All Services" button
6. **Footer** — Contact info, social links, copyright

### Design Details
- Elegant, soft aesthetic with rounded elements
- Gold sparkle/star decorative accents throughout
- Buttons: rounded with primary gold color
- Section dividers with decorative lines
- Smooth scroll navigation
- Fully responsive (mobile-friendly)
